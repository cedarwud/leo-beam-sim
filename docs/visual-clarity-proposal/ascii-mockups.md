# ASCII 線框示意（讓建議可被「看見」）

> 對應 README §4「推薦組合」的視覺化呈現。每個示意都用同一個情境：
> - UE 在中央地面（0,0）
> - 三顆衛星在天上：**Sat-A（serving）/ Sat-B（pending）/ Sat-C（approach）**
> - Sat-A 的 serving beam 是 F2 / B5
> - Sat-B 的 pending beam 是 F1 / B3
> - Sat-C 的 approach beam 是 F4 / B11

---

```
                          ◆Sat-A          ◆Sat-B         ◆Sat-C
                          (青標)          (金標)         (紫標)
                          ╱                ╲              │
                         ╱                  ╲              │
                        ╱                    ╲             │

                     ╱  〔SERVING  F2 B5〕    ╲ 〔PENDING F1 B3〕  〔APPROACH F4 B11〕
                    ╱      18.4 dB             ╲    14.8 dB             —— dB
                   ●──────────────●──────────●──────────●──────────●
                   Sat-A's        Sat-A's    Sat-B's    Sat-B's    Sat-C's
                   F2 B5 (青)      F4 B11(粉) F1 B3(金)  F2 B5(綠) F4 B11(粉)

  問題:
    • 圖右側 Sat-B 的 F2 B5 跟 Sat-A 的 F2 B5 顏色完全一樣
    • Sat-B 的 F4 B11 跟 Sat-C 的 F4 B11 也完全一樣
    • 只有 SERVING/PENDING/APPROACH event-role 那 3 個讓人看得出來

```

```
                   Sat-A 服務區（青藍）        Sat-B 候選區（金）       Sat-C approach（紫）
```

## 4. 階段三（故事化版）：地面 hex 格網 paint-by-numbers

```
                          ▲Sat-A          ◆Sat-B           ●Sat-C
                          │                │                │
                          │                │                │
                          │                │                │
                          ▼                ▼                ▼
                  ┌──────────────────────────────────────────────────┐
                  │  ⬡   ⬡   ⬡   ⬡   ⬡                                │
                  │   ⬡A2 ⬡A2 ⬡   ⬡   ⬡                              │
                  │  ⬡   ⬡A2 ⬡A2 ⬡B1 ⬡C4                              │
                  │   ⬡A2*⬡A2 ⬡A2 ⬡B1 ⬡C4 ⬡                          │  ← UE 在這附近
                  │  ⬡   ⬡   ⬡A2 ⬡B1 ⬡B1 ⬡C4                          │
                  │   ⬡   ⬡   ⬡   ⬡B1 ⬡C4 ⬡                          │
                  └──────────────────────────────────────────────────┘
                  hex 格網重新利用：每格被誰的波束覆蓋就上誰的色
                    格外框  = 衛星色 (A=白, B=米, C=淡紫)
                    格填色  = 頻率色 (A2 fill 綠, B1 fill 黃, C4 fill 桃)
                    ⬡A2*    = UE 所在格，用粗外框 + 角色色內描
                    每格右下小字 "A2"/"B1"/"C4" 是 sat·beamId 速記

                  + spine 粒子流動畫（衛星色光點從 apex 滴下）
                  + 衛星軌道拖尾（衛星色短線跟隨衛星移動）

  改善:
    ✓ 地面變成「歸屬地圖」，故事性極強
    ✓ 即使去掉所有空中圓錐，光看地面就能讀出整個劇情
    ✓ 動畫的 pre-attentive 通道把「資料在流」這件事直接呈現
```
