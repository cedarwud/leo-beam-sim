## 我判斷不該抽的

- `SceneRenderContent` 目前的 `tween`（現行約第 3891 行）留在原處。它位於 `useFrame`，以 `cameraTweenRef.current` 為可變輸入，直接呼叫 `camera.position.lerpVectors`、`controls.target.lerpVectors`、`controls.update`，並清除/更新 `cameraTweenRef`、`directorSnapshotRef`、`directorFocusOrbitRef`、`cameraPresetRef`、`cameraTransitionRef`。這不是可由輸入產生明確值的 pure derivation；抽成 hook 只會搬動副作用，無法寫出符合驗收標準的 React-free value test。Artifact scene 中另一個同名 camera tween 也同屬此理由，未擴大本次範圍。

- `beamInfoItems` 沒有因為最後被 JSX 使用就判定為 UI tree；其實它只產生 items list，已抽到 pure module。真正的 JSX return tree 與 camera owner 沒有被搬動。
