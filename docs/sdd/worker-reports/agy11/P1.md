## 我認為 N1 最可能錯的一點

**N1 過度自信地將「靜態依賴分析上的無 Consumer」等同於「執行期無業務行為價值」，低估了跨 Lane 切換（Lane Switch）時的狀態連續性風險。**

* **核心盲點**：N1 認為 `archivedTleTimelineCurrentTimeRef` 只有 archived playback effect 讀取，因此在 Walker 活躍期間寫入它「沒有行為價值」。但它忽略了 `ref` 在 React 動畫與傳輸層中常被用作「跨模式切換時的狀態傳遞媒介」。
* **潛在後果**：如果原作者設計該反向邊的目的是為了在 Lane 切換時讓 Archived 自動繼承 Walker 的當前播放進度（或者反向承接），切斷這條邊（選項 B）將直接破壞跨模式的時間連續性；加之現有測試對此完全空白，此改動有高度機率引入難以排查的動態 Playhead 跳變 Bug。
