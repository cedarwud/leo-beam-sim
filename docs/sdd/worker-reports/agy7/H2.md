### 一、 判定：G2 時序假說的「推翻」與「確認」

1. **推翻 G2 的「暫停後 1500ms 等待導致淡出」假說**：
   - **證據（材料 B）**：`sinrLiveCellModel.test.ts:332` 明確定義 `live-pulse handover events fade out of the retention window by sim-time`。
   - **結論**：Pulse 的生命週期與消逝機制完全綁定在**模擬時鐘（`simTimeSec`）**，而非真實世界的物理時鐘（wall-clock time）。
   - **推翻理由**：一旦模擬器進入 `paused` 狀態，`simTimeSec` 停止遞增，物理時間經過 1500ms **絕對不會**導致 pulse 在模型中淡出。因此「暫停後等待 1500ms 讓 pulse 消失」的猜想被材料推翻。

2. **確認並鎖定真正的時序根因：20 倍速播放下的取樣與暫停延遲**：
   - **時序計算**：在 20 倍速播放下，真實時間 500ms 等同於模擬時間前進了 **10 秒**（$0.5\text{s} \times 20 = 10\text{s}$）。
   - **競爭點**：Handover pulse 在 `sim-time` 中的 retention window 通常僅有數秒。若在 20x 速度下以 500ms 輪詢：
     - Pulse 可能在兩次 500ms 輪詢之間產生並在 `sim-time` 內直接結束（完全踩空）。
     - 即使 500ms 輪詢恰好抓到 `count > 0`，從 Node.js 透過 CDP 發送暫停指令到瀏覽器主執行緒實際停止模擬，其間數十至數百毫秒的延遲在 20x 倍速下已被放大 20 倍，導致暫停生效時 `simTimeSec` 已超出 pulse 的 retention window，pulse 已消逝（`count` 歸零）。

### 二、 具體修法與斷言強度評估

#### 1. 修改方向與常數調整
- **不要在 20x 高倍速下捕捉暫停幀**：在接近預期 pulse 觸發區間時將倍速降至 **1x**（或全程 1x 播放至捕捉到為止），讓 pulse 在真實時間中維持足夠秒數供 Playwright 攔截。
- **以瀏覽器端 `page.waitForFunction` 取代 Node.js 端的 500ms 輪詢**：將輪詢移至瀏覽器的 `requestAnimationFrame` 週程中，直接監聽 `c.dataset.sinrLiveHandoverPulseConeCount`。
- **順序調整**：透過 `waitForFunction` 偵測到 `count > 0` 後立刻凍結（pause），再以 `readSnap(page)` 擷取 settled 幀。

#### 2. 為什麼不會讓斷言變弱？
- 測試的核心閘門要求是：**在有 pulse 的狀態下（$\text{count} > 0$），渲染錐體數必須等於事件計數（$\text{count} == \text{rendered}$）**。
- 將高倍速降為 1x 或提升取樣頻率，只是**讓取樣點精準落在 pulse 的有效 `simTimeSec` 視窗內**，並沒有放寬 `count > 0` 或 `count === rendered` 的任何等式條件。測試依然嚴格檢驗 settled 狀態下的渲染完整性。

#### 3. 可貼核心邏輯片段（基於材料 A 的 `readSnap` 與 `CANVAS`）

```ts
// 1. 在瀏覽器端以 requestAnimationFrame 等待 lit-pulse 出現 (count > 0)
await page.waitForFunction((canvasSel) => {
  const c = document.querySelector(canvasSel) as HTMLElement | null;
  const count = Number(c?.dataset.sinrLiveHandoverPulseConeCount ?? 0);
  return !Number.isNaN(count) && count > 0;
}, CANVAS, { timeout: 10000 });

// 2. 觸發暫停（需使用原本測試中的暫停操作，此時 simTimeSec 凍結，pulse 不會消逝）

// 3. 讀取 settled 幀並驗證斷言
const snap = await readSnap(page);
if (Number.isNaN(snap.count) || snap.count <= 0) {
  throw new Error(`Failed to capture a lit-pulse frame (count: ${snap.count})`);
}
```
