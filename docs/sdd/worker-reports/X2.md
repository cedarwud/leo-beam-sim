## 複合斷言與孤兒 pass 的處理

- 複合斷言：0 個。18 條都是獨立 source-text 斷言，沒有移除任何同一斷言內的其他條件。
- 獨立對應的 `recordPass(...)` / `pass(...)` / `PASSED.push(...)`：0 個。這些 validator 的逐條 pass 都由 `assert` / `check` / `assertContains` helper 在斷言成功後內部記錄；刪除呼叫後不會留下假的逐條 pass。
- `validate-live-walker-handover-event-focus.tsx` 的函式末尾 aggregate `PASS:` 仍由同函式內其餘五條有效 source-owner、horizon 與 rail 邊界斷言支撐，因此保留。
- 數量 ratchet：0 個；沒有調整任何門檻或數字。
