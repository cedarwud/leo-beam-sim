## 最該退回的前 3 條

1. **L2184 (`modqnIdleUeCount`) — 嚴重的「假安全」削弱斷言**
   - **原因**：原斷言是三元運算式 `show ? idleCount : 0`，提案竟聲稱「只在 parked 狀態下驗證等於 0 就足夠」，完全放棄了解除 parked（非 0 分支）時傳遞真實 `idleUeCount` 的驗證。若重構時將屬性誤寫死為 `modqnIdleUeCount={0}`，此提案依然 100% 全綠，但原本要保護的 idle UE 傳遞功能已徹底損壞。
2. **L2117 (`showUav = sceneLane === 'sinr-live'`) — 同時踩中兩個死碼 selector**
   - **原因**：提案規劃透過點擊 `[data-testid="lane-experience-modqn-live-cell-preview"]` 與 `[data-testid="lane-experience-sinr-live"]` 來驗證 UAV 顯示邏輯。這兩個 selector 所在的元件是完全未被掛載的死碼，執行期永遠不會出現在 DOM 中，Playwright 執行時會在點擊步驟直接超時崩潰。
3. **L2174 (`showUeCounts`) — 依賴幽靈 selector 且落點在紅閘門**
   - **原因**：提案要求點擊 `[data-testid="advanced-setup-trigger"]` 打開 Drawer，但該 selector 在 `src/` 中根本不存在，測試無法完成前置操作；且其規劃擴充的 `validate-phase-3-overlay-render-browser.ts` 目前亦為紅閘門，屬於雙重無效提案。
