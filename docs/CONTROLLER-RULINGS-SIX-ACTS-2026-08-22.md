## 【裁決 1】ξ ⇒ **保留 √p,但改用論文式 (3.15a),而且要補 min 夾制。**

論文式 (3.15a):

```
ξ = min{ ξ_max , ξ_max · √( p_{s,v}(t) / p_sat ) },   p_sat = p_max · 10^(BO/10)
ξ_max = 0.35,  BO = 5 dB,  p_max = 1.65 W  ⇒  p_sat = 5.218 W
```

你的版本 `ξ = 0.35·√(p/1.65)` 有**兩個錯**:

| | 你的 | 論文 | 後果 |
|---|---|---|---|
| 分母 | `p_max = 1.65 W` | `p_sat = 5.218 W` | @p=2 W,你算出 ξ=0.385,論文是 **0.217**,差 1.78 倍 |
| 夾制 | 無 | `min{ξ_max, …}` | 你的 ξ 在 p>1.65 W 時**超過 ξ_max=0.35**,物理上不可能 |

順帶一提,`p_sat = 5.218 W` 就是 ch5 表裡的 `P_0 = 5.218 W`,兩邊對得起來。

**教學敘事不用改成「線性 vs log」,反而變好講了**,因為 √p 現在**有出處**,不是 DEMO 值:

- 論文的理由寫在式 (3.15a) 下方:類 B 放大器 `P_RF ∝ V_o²`、`P_DC ∝ V_o`
  ⇒ `ξ = P_RF/P_DC ∝ √P_RF`。射頻輸出為飽和功率四分之一時,效率是 `ξ_max/2` 而不是 `ξ_max/4`。
- 帶進去:飽和點以下 `P^p = p/ξ = √(p·p_sat)/ξ_max`,所以**抽取功率 ∝ √p**;
  輻射功率加倍,消耗只增加 1.414 倍。
- 這就是論文自己寫的那句:「**把發射功率壓低並不會等比例降低功率消耗**」——
  也正是第一個目標用 EE 而不是用單純發射功率的**全部理由**。Act 5 的右段就是在演這件事。

所以:**移除 DEMO 徽章,換成引用式 (3.15a)。** 三段式右段的文字從
「cap 內 ξ∝√p」改成「飽和點以下 ξ∝√p ⇒ P^p∝√p」(是 `p_sat` 不是 cap)。

> 同一個錯我今天在論文簡報 part2 第 14 頁也犯了(寫成「抽取功率以同一倍數上升」),
> 已修正並補上 (3.15a) 的完整式子。你和我原本錯在同一個地方。

## 【裁決 2】P^f ⇒ **用 ADR-006/論文 (3.16a) 的公式,但 `N_act` 必須「算出來」,不可寫死 7。**

公式確認,與論文 (3.16a) 一致:

```
P^f(t) = Σ_s ( N^act_s(t) · P_cir + 1{N^act_s(t)>0} · P_BB )
P_cir = 0.338 W,  P_BB = 0.200 W   [You 等人 Table II, 參考文獻 25]
```

7 beam / 1 sat 代入 = **2.566 W**(你算的沒錯)。

**但關鍵在別的地方:`N^act_s(t)` 是由 `z_{s,v}(t) = 1{U_{s,v}(t)>0}` 導出的,會隨場景變。**
如果你把 7 寫死,`P^f` 就又變成一個常數 —— 只是換了一個比較好聽的出處,
而且**「關掉沒人用的波束可以省電」這個教學點會整個消失**。那正是 `P^f` 存在的意義。

所以:滑桿改變負載時,`N^act` 要跟著變,`P^f` 要跟著動。
`N_active_satellite` 同理,用 `1{N^act_s>0}`。

## 【裁決 3】η 口徑 ⇒ **教系統級 ratio-of-sums,改標籤。而且要順便講「兩者是同一件事」。**

你算的 `Σ_u R / P^N` 是**系統級**,標籤寫 `η` 不對,符號表第 256 行切得很清楚。
把標籤改成系統能量效率。

**但不要只是改標籤,這裡有一個免費的教學點:** 論文的 `r_{1,u}` 是

```
r_{1,u}(t) = Σ_s Σ_v x_{u,s,v}(t) · η_{u,s,v}(t),   η_{u,s,v} = R_{u,s,v} / P^N
```

分母對每位使用者是**同一個** `P^N`。所以

```
Σ_u r_{1,u}(t) = ( Σ_u R_u(t) ) / P^N(t)  =  你畫的那條曲線
```

也就是說:**逐使用者獎勵加總起來,恰好等於系統級 EE**。這不是巧合,是論文刻意設計的
可加分解 —— 每個人拿到的獎勵是他對系統指標的那一份貢獻,不是大家分攤同一個數字。

Act 5 講這一句,標籤問題就從「改錯字」變成「講清楚兩個層級的關係」。

## 【裁決 4】κ ⇒ **(a) 有模型。(b) κ=2 留著,但拿掉 COURSE-ASSUMPTION,改成推導值。**

**(a) 論文端有:式 (3.12a)(3.12b)。** 干擾是「**同色**且**已啟用**」波束的發射功率,
乘上各自的 `G^T(θ')` 與 `H'`,分成同衛星 intra 與跨衛星 inter 兩項相加。

**(b) 你的 `I(p) = κ·p·(訊號基準)` 不用丟掉 —— 它是 (3.12a/b) 的平均場化簡,
而且 κ=2 可以直接推出來,不是你挑的。**

推導:

1. 為什麼干擾隨**這條鏈路自己的** p 上升?因為所有同色波束在同一時間套用**同一條**
   角度功率規則(論文式 3.11)。角度一起變大,大家的功率一起往上補。
   所以用自己的 p 當代理量是合理的 —— 這一點論文簡報 part2 第 12 頁講的就是這件事。
2. κ 的數值 = 同色共頻鄰居數 × 幾何相對強度。三色重用、7 波束場景下:
   **每支波束的同色鄰居 = (7−1)/3 = 2.00**。
3. 取「鄰居幾何與自己相當」為簡化,得 **κ = 2**。

所以徽章從 `COURSE-ASSUMPTION` 改成:
**「κ = 同色鄰居數 = (7−1)/3 = 2(三色重用);已簡化為鄰居幾何相當」**,
被簡化掉的那一項(幾何相對強度 = 1)才是要揭露的假設。

你發現「沒有這一項速率永遠不飽和」是對的,而且那正是真實系統的行為:
功率一起漲,SINR 不會一起漲。這個發現值得寫進 Act 5 的講稿。

⚠ 但注意:κ 決定 `γ` 上限 ≈ 1/κ = −3.0 dB,這仍然壓在引擎 −5 dB 門檻附近。
你選 κ=2 讓陷阱演得出來 —— 現在它有推導了,**但要驗一次 `LOW_SINR_RATIO` 的
100%→75%→50% 是不是仍然成立**;若不成立,回報,不要為了讓它成立去調 κ。
